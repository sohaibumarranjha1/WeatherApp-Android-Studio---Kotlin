# WeatherApp — Android Studio & Kotlin

## Overview
I built this Weather App using Kotlin in Android Studio to fetch and display weather information through a weather API.

## Features
- **Live Weather Data:** Fetches weather information from an API.
- **Temperature Details:** Displays the current temperature for the selected location.
- **Weather Conditions:** Shows weather conditions such as sunny, cloudy, or rainy, depending on the API response.
- **Location-Based Search:** Allows users to check weather information for a selected city, if supported by the app.
- **API Integration:** Uses Retrofit to handle API requests and retrieve weather data.
- **User-Friendly Interface:** Provides a simple and clean interface for viewing weather information.
- **Dynamic Data:** Updates displayed weather information when a new successful API response is received.
- **Error Handling:** Handles unsuccessful requests or network issues where implemented.

## Tech Stack
- Kotlin
- Android Studio
- Retrofit
- Weather API

## Setup & Usage
1. Clone this repository:
   ```bash
   git clone https://github.com/sohaibumarranjha1/WeatherApp-Android-Studio---Kotlin.git
   ```
2. Open the project in Android Studio.
3. Wait for Gradle sync to finish.
4. Add your weather API key if required by the project.
5. Run the app on an Android emulator or physical device.
6. Search for a city or use the available features to view weather information.
